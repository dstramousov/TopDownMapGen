# forest_asset_pack_v2

Оригинальный тестовый набор ассетов для `ForestMassOverlay cleanup`.

`ideal.png` использовался только как визуальный ориентир. Пиксели из него не вырезались.

## Главное отличие от v1

Это уже не просто набор ёлок. Ассеты сгруппированы по условиям лесной маски:

- `deep/` — плотная глубокая масса леса.
- `mid/` — средняя плотность леса.
- `edge_front/` — нижний/передний край леса.
- `edge_back/` — верхний/задний край леса.
- `edge_side/` — левый/правый боковой край.
- `corners/` — внешние углы лесной массы.
- `thin_strips/` — узкие перемычки.
- `islands/` — маленькие/средние острова леса.
- `context_road/` — край леса рядом с дорогой.
- `context_ruins/` — лес рядом с руинами.
- `context_water/` — влажный край у воды/болота.
- `guards/` — безопасные ассеты для края карты и защиты от обрезки.
- `ground/` — прозрачные подложки под лесную массу.
- `shadows/` — мягкие тени.

## Как подключать

1. Сначала классифицировать точку/регион леса по `rules/forest_asset_rules_v2.json`.
2. Для `map_border_guard` запрещать большие кластеры, если полный bounds выходит за canvas.
3. Для `edge_*` использовать специальные edge/corner ассеты, не deep-кластеры.
4. Для `mid/deep` использовать кластеры и floor/shadow overlays.
5. Все деревья и кластеры сортировать по `anchor_y` / world y.
6. Ground/shadow overlays рисовать до деревьев.

## Что это не такое

Это не финальный коммерческий арт. Это рабочий pack, чтобы проверить алгоритм заливки леса по условиям.
